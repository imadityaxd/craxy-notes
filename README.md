📚 LU FOET Notes Portal

The LU FOET Notes Portal is a secure, full-stack application providing organized study materials for students of the Faculty of Engineering & Technology (FOET) at Lucknow University.

Key Features:

Hierarchical Filtering: Browse notes precisely by Branch and Semester.

Technology Stack: Built using React, Express, Node, Firestore, and Cloudinary (MEFRC Stack).

Security: Implements Role-Based Access Control (RBAC) via Firebase Auth to restrict uploads to verified admin and contributor accounts only.

Deployment: Designed for scalable cloud hosting (Render/Netlify).
